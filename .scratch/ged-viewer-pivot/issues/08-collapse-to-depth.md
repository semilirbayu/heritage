# 08: Collapse or expand a branch to a depth

**What to build:** One action collapses or expands a branch to a chosen depth. Placeholder cards make the collapsed result readable. This is the tool that keeps charts with many branches legible.

**Blocked by:** 07: Placeholder cards and an honest truncation notice
